## Filter definition

### Included
- ARM CPU acceleration, feature detection, dispatch, GEMM/GEMV, repack, NEON, dotprod, i8mm, SVE, SME/SME2, KleidiAI, and ARM quantized kernels.
- Shared `ggml-cpu` vector, norm, attention, threading, repack, quantization, and dispatch changes that can affect ARM paths, even when the PR title is not ARM-specific.
- Model quantization formats, GGUF/HF conversion, quantization tooling, tensor-type selection, quantization metadata, and quantized model loader/runtime changes.
- Runtime/KV-cache quantization is retained as a separate secondary group; it is not mixed with weight quantization.

### Excluded
- Backend-only CUDA/SYCL/Vulkan/OpenCL/WebGPU/Hexagon/ZendNN quantization kernels without shared format or model-loader changes.
- CPU-only RVV, x86/AVX, s390x, PowerPC, WASM, and other non-ARM architecture implementations when they do not change shared quantization semantics.
- CI, UI, server, docs-only, and unrelated model-architecture PRs.
- Revert commits are retained only as history markers, not as positive candidates.

- ARM repack and KleidiAI PRs are performance references, not direct implementation recipes for Fairy2i tile/LUT kernels.
- Conversion and quantization-format PRs are useful for schema, scale, tensor-type, and metadata handling; they do not imply compatibility with Fairy2i bundle layouts.
