# Android Documentation

The maintained Android build and test guide lives in:

- `examples/llama.android/README.md`

Use that document for:

- fresh Linux environment setup
- Android SDK, NDK, CMake, and JDK requirements
- CPU and OpenCL APK builds
- model assets packaging
- install, smoke test, and benchmark commands
- troubleshooting

Historical Android prototype notes from the April 2026 bring-up have been removed from the repository root. They contained session-specific local paths, early benchmark numbers, and dispatch-debug notes that are no longer a reliable source of truth for the current Android app.
